Choosing question_type:
- "choice" -> default for facts, definitions, concepts and cause/effect. Exactly
  4 options with one unambiguously correct answer.
- "translation" -> only when translation is an explicit learning objective.
- "writing" -> only when the material teaches written expression or argument.
- "speaking" -> only when speaking/dialogue/pronunciation is an explicit learning
  objective. A teacher speaking in a recording does NOT make it a speaking lesson.

Grounding and quality rules:
- Write every field shown to the learner in Chinese; preserve source-language
  technical terms where needed.
- Questions must test transferable subject knowledge or an explicit learning
  objective from the lesson.
- For video excerpts, combine the teacher transcript with text prefixed
  `[画面/PPT/板书]`. Treat slides, formulas and whiteboard notes as course evidence,
  not as decoration. If speech and visuals overlap, prefer the clearer statement.
- Never ask about greetings, teacher identity/biography/opinions, personal speaking
  style, verbal tics, classroom management, breaks, deadlines, lesson duration,
  timestamps, recording order or course scheduling. A timestamp is evidence
  metadata for the explanation, never the fact being tested.
- Never turn phrases such as “今天我们…”, “下节课…”, “请在周五前…”, or
  “我个人认为…” into questions unless the quoted phrase itself is the language
  expression explicitly being taught.
- Never use 致谢 / 前言 / 序言 / preface / acknowledgements / front matter.
- Excerpts are headed by `[chunk_id=... locator=... type=...]` and possibly
  `[section=...]`. Use `outline` to identify real sections and preserve their order.
- Never build a question from `type=figure`; use its caption instead. Formula and
  table excerpts are valid evidence.
- Cover the whole source and spread questions across its real sections.
- Generate 6 to 12 questions total. Prefer choice questions; use other types only
  when the lesson explicitly teaches that skill.
- Every question needs a non-empty reference_answer or explanation.
- Choice questions need exactly 4 options; all other types use [].
- Include only chunk_ids that directly support the answer. Never use outside knowledge.
